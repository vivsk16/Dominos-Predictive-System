# Dominos-Predictive-System
Dominos - Predictive Purchase Order System

📌 Project Overview

Dominos wants to optimize its ingredient ordering process by predicting future sales and generating purchase orders. This project leverages historical sales data and ingredient information to build a predictive model, ensuring optimal stock levels, minimizing waste, and preventing stockouts.

🎯 Business Use Cases

Inventory Management: Maintain optimal stock levels.

Cost Reduction: Reduce waste and unnecessary expenses.

Sales Forecasting: Predict sales trends accurately.

Supply Chain Optimization: Streamline the ingredient ordering process.

🛠️ Tech Stack & Tools

Programming Language: Python

Libraries: Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn, Statsmodels, Prophet

Version Control: Git & GitHub

Data Handling: CSV, Excel

Time Series Forecasting Models: ARIMA, SARIMA, Prophet, LSTM, Regression

📂 Dataset

1. Sales Dataset

Date: Transaction date

Pizza Type: Type of pizza sold

Quantity Sold: Number of pizzas sold

Price: Sale price per unit

Category: Type of pizza (Veg/Non-Veg)

Ingredients: List of ingredients used per pizza

2. Ingredients Dataset

Pizza Type: Type of pizza

Ingredient: Required ingredient for each pizza

Quantity Needed: Quantity required per pizza

🚀 Project Workflow

Data Loading & Cleaning

Read sales and ingredients datasets

Handle missing values and duplicates

Convert date formats

Exploratory Data Analysis (EDA)

Identify sales trends, seasonality, and patterns

Visualize data using Matplotlib & Seaborn

Feature Engineering

Extract date-based features (day, month, holiday, promotion period)

Create categorical and numerical features

Sales Forecasting

Train time series models (ARIMA, SARIMA, Prophet, LSTM, Regression)

Evaluate models using Mean Absolute Percentage Error (MAPE)

Forecast sales for the next week

Purchase Order Generation

Calculate required ingredients based on forecasted sales

Generate a structured purchase order

Results & Documentation

Store findings in a report

Generate visualizations & insights

Upload code and findings to GitHub
